# Discrete Probability Distributions

A small website I made for my AIML lab (SDAV Lab Program 01). It helps you work out and see probabilities for three common distributions: Binomial, Poisson and Geometric.

**Try it here:** https://rakesh-madannavar.github.io/SDAV_Lab_Program_01/

## What it does

You type in some numbers, and the page instantly shows you:

- the probability of your result
- the cumulative probability (the chance of getting that value or less)
- a bar chart of all the possible outcomes
- basic statistics like mean, variance and standard deviation

If you type something invalid, like a probability greater than 1, it tells you what's wrong.
